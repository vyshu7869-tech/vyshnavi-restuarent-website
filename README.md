# The Hungry Tale

A premium, fully responsive frontend-only restaurant management website built with HTML5, CSS3, and Vanilla JavaScript.

## Pages
- Home (`index.html`)
- Menu (`menu.html`)
- About (`about.html`)
- Gallery (`gallery.html`)
- Reservations (`reservations.html`)
- Contact (`contact.html`)

## Features
- Sticky responsive navbar with mobile hamburger menu
- Premium cinematic hero section
- Menu filtering by category
- Gallery filtering and fullscreen lightbox
- Animated counters
- Reservation form validation with localStorage
- Contact form validation
- Add-to-order system with quantity controls
- Subtotal, tax, and grand total calculation
- Order storage in localStorage
- Back-to-top button
- Loading animation and scroll reveal effects

## Run
Open the project folder in VS Code and launch `index.html` using Live Server.

## Notes
- No backend is used.
- All interactions are handled with vanilla JavaScript.
- External images use reliable Unsplash URLs.
